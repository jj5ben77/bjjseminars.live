# Seminar intake

For every seminar added or updated, check that its host gym exists in directory.csv before presenting the preview. Match case-insensitively using Instagram username, gym name, website, and obvious naming variants; avoid duplicate locations or renamed gyms.

When the user authorizes adding seminars, also add any verified missing host gyms to the same preview. Verify official Instagram accounts and available address/website details from the source; leave unknown fields blank rather than guessing. Report any host gym that cannot be verified. Keep preview changes local until the user requests publishing.
