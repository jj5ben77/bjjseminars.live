# Changelog

Public updates to [BJJ Seminars Live](https://bjjseminars.live/) are documented here by release date.

## 2026-10-01

### Added

- Added **This Week**, **Next Week**, **New Events**, and **This Month** quick searches.
- Added dynamic seminar carousels whose titles and posters follow the selected quick search.
- Added **New Jersey** and **New York** Area filtering to the seminar carousel.
- Added combined titles and poster filtering when a quick search and one Area are selected together.
- Added a two-poster minimum for filtered carousels; smaller result sets remain available in the event list without displaying a carousel.

### Changed

- Selecting both New Jersey and New York restores the default **This Month's Seminars** carousel.
- Clicking an active quick search again clears it and restores the default carousel.
- Upcoming quick searches hide the **Previous Seminars** carousel, while the 2026 view keeps it visible.
- ZIP searches now focus on current-month seminars.
- Improved quick-search and ZIP behavior on mobile.

### Fixed

- Corrected the date ranges used by **This Week** and **Next Week**.
- Fixed event filtering for New York so it includes NYC, Long Island, and New York State.
- Fixed ZIP-code event searches.

### Removed

- Removed the automatic dark/light theme animation after mobile testing. The manual theme control remains available.
